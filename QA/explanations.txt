RECOMMENDATION: Split the "count consecutive detections" logic out

no camera needed. The camera component just feeds events into this
state machine.

ANALOGY: Imagine you're building a coffee vending machine. If you

and real cups every time. If you separate out the "count coins →
decide if enough" bit into its own module, you can test THAT part
with fake coin inputs — no plumbing required.

CONCERN #10 — MEDIUM — What happens if the user's face never enters the oval?
----------------------------------------------------------------

WHAT THE PLAN SAYS: Nothing. The plan describes success. It does not
describe the failure mode where the auto-detector never fires —
because of bad lighting, camera angle, user wearing sunglasses,
detector confused by beard/turban, whatever.

THE PROBLEM: Without an escape hatch, the user is stuck on page 31
staring at a black screen with an oval overlay, forever. This is a
"critical path" screen — if they can't get past it, they can't finish
signing up.

OPTIONS:

  OPTION A — Timeout with manual shutter fallback
     - After N seconds (say 20-30) with no detection, show a manual
       "shutter" button. User taps it, we save whatever's in the
       viewfinder as their selfie.

  OPTION B — Always show a manual shutter alongside auto-capture
     - User can tap the shutter any time. Auto-capture still fires
       if the detector likes what it sees, whichever happens first.
     - More forgiving. Muzz and Bumble both do this.

  OPTION C — Retry button only
     - After a timeout, show "we couldn't detect your face — try
       again" with a retry button that resets the frame counter. No
       manual shutter.
     - More strict, might frustrate people who just want to finish.

  OPTION D — No timeout at all (current PRD behavior)
     - User has to stand there until the detector fires. Or force-
       kill the app. Not recommended.

RECOMMENDATION: Option B. Auto-capture for the smooth path, always-
available shutter as a safety net. Adds one small button but
massively reduces "user stuck forever" risk.

ANSWER (A / B / C / D): Option B
